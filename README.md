# Circuit Analyzer

A Python-based DC circuit analyzer using graph theory and nodal analysis.

## Planned Features

- Represent electrical circuits as graphs of nodes and components
- Automatically analyze DC circuits using nodal analysis
- Calculate voltages, currents, and power
- Compare calculated values with laboratory measurements
- Visualize circuit connections

## Current Status

Version 0.1 — Project initialization and circuit representation.

## Technology

Python, NumPy, NetworkX, Matplotlib
